# QPAD 返修实验协议

配置固定于 `configs/necessary.json`，运行时复制到输出目录。每个输入只在各方法默认配置下拟合一次；C 在两个固定输入上改变初值。实验结果用于判断方法的有效性和适用范围。

## A/B 共用比较

- 方法：QPAD、STL、VMD、QPGP、按周期排列矩阵的 RPCA。
- 真实：全部 88 个片段，按文件名末尾片段编号之前的部分识别原始录音组。标签来自已有人工作图矩形的并集，不能将未标注点直接解释成已验证的健康状态。
- 仿真：35 条新生成信号，替换返修仿真比较所用的数据表。新旧表的样本数和场景不同，正文需对应更新。
- 所有方法在同一输入上评价，保留逐信号结果和数值失败；未定义指标为空，实际零分保留。
- 本协议没有使用测试异常标签选择超参数、候选周期或阈值。QPAD 固定参数继承已有代码，历史参数选择过程仍需作者说明。

## 仿真定义

长度 2000、名义周期 200。每个周期的起点抖动最多约 10 点，活动时长约 100 点并有 ±8% 变化，幅值在 1.7–2.3 之间。背景、异常位置、噪声分别使用由种子派生的独立随机数流。相同种子跨场景尽可能共用随机扰动，以便判断单一因素变化；种子 0–4 是独立重复。

| 场景 | 设置 |
|---|---|
| nominal | 局部正弦单峰背景，正向局部隆起及短尖峰，噪声标准差 0.2 |
| asymmetric | 将活动区间相位 u 替换为 u^2.2，其余与 nominal 配套 |
| double_peak | 活动区间内采用双峰包络，其余与 nominal 配套 |
| high_noise | nominal 背景与异常，噪声标准差增加到 0.4 |
| negative | 正常事件内部发生局部能量下降，A = −0.7P，P+A 仍非负 |
| bidirectional | 一处正向事件、一处局部能量下降 |
| normal | 无异常，仅正常背景和噪声 |

事件支持区间独立生成二值标签，包含负向异常；真值端点、噪声均不参与阈值调参。每条输入保存 X、P_true、A_true、noise、labels。A/B 的统计来自这批配套数据，不读取历史同名仿真真值。

## QPAD

`models/simulation.py` 和 `models/real.py` 的三个核心定义由原脚本逐段提取；来源哈希见 `models/provenance.json`。运行入口显式选择设备，调用原 `compute_loss`，以原 Adam 更新及 10 倍目标缩放执行。

| 设置 | 仿真 | 真实 |
|---|---:|---:|
| K | 10 | 12 |
| 初始活动时长/采样点 | 100 | 150 |
| 初始起点 | 在 [0,N) 均匀放置 | 在 [250,N) 均匀放置 |
| 初始事件幅值 | 1 | 1 |
| 初始 A 参数 | 0 | 0 |
| λ1、λ2 | 1.5、1 | 1.5、1 |
| η1、η2、η3 | 0.15、0.15、0.05 | 0.3、0.3、0.1 |
| ψ | 2 | 10 |
| Adam 学习率 | 0.01 | 0.01 |
| 固定迭代次数 | 2000 | 1500 |

归档实现包含未施加局部支持的模板、整数切片相似性项和 LeakyReLU 异常输出。LeakyReLU 允许负值；本实验不能作为严格非负约束、投影 AMSGrad 或唯一分解定理的实现验证。代码与稿件描述需按实际保留的方法对齐。这里不预先声称初值稳定或分解准确。

## 基线与参数

### 周期估计

使用当前无标签输入：按中位数与 3 MAD 截幅，Gaussian σ=1.5 点平滑，再计算自相关。在 [0.025N, 0.25N] 的采样点区间内，取达到最高峰 85% 的首个正峰；没有符合条件的局部峰时取最大自相关位置。所有估计和搜索范围随输出保存。STL、QPGP 和 RPCA 共享该周期估计，VMD 使用其频率分解。

QPAD 使用原代码固定 K 和初始化；这一实现先验在正文中明确列出。基线使用数据估计周期，消除原先将“周期个数”当作“每周期采样点数”的单位问题。

### STL

调用 `statsmodels.tsa.seasonal.STL`，`robust=True`，`period` 为上述采样点周期，其他设置采用库默认值。P 为 trend+seasonal，A 为未截断残差。[官方接口](https://www.statsmodels.org/stable/generated/statsmodels.tsa.seasonal.STL.html)。

### VMD

使用 `vmdpy==0.2`：α=2000，τ=0，K=4，DC=False，init=1，tol=1e−7。按**最终中心频率排序**后取最低两个模式之和为 P，A=X−P。奇数长度先在末端补一个点，输出裁回原长度。[Python 实现](https://github.com/vrcarva/vmdpy)。

### QPGP

依据 [Li 等作者代码](https://github.com/Yongxiang-Li/QPGP/tree/329168e14548266df77e08cc2da96e4266d4c023) 中的网格协方差，独立实现 Python 求解：

\[
C_{ij}=\exp[-\theta^2\sin^2(\pi(i-j)/p)]\,
\omega^{|\lfloor i/p\rfloor-\lfloor j/p\rfloor|}+\delta^2 I_{ij}.
\]

对完整周期使用 FFT 和周期间矩阵特征分解；末尾不完整周期用 Schur 补，所有观测均参与似然。常数均值 β 和总体方差通过广义最小二乘/剖面似然估计。

候选周期为估计值的 0.9/1.0/1.1 倍取整。每个周期检查 4 个固定起点 `(δ,θ,ω)`：`(0.2,1,0.5)`、`(0.5,3,0.9)`、`(1,1,0.9)`、`(0.2,5,0.5)`；从其中似然最优者启动 L-BFGS-B，最多 40 次迭代。边界 δ∈[0.03,3]、θ∈[0.2,10]、ω∈[0.01,0.999]，正参数在 log 坐标优化。按无标签似然选择最终周期及参数，保存所有候选、停止信息。

背景使用包含协方差项的完整条件均值。对于观测网格，令 α=C^−1(y−β)，标准化背景为 y−δ²α；恢复原尺度后取 A=X−P。数学求解已与直接稠密协方差计算对照；这里的搜索器与 Python 实现由本项目提供。

### 周期矩阵 RPCA

将序列按估计周期 p 排列成 p×ceil(N/p) 矩阵，最后不完整列从输入开头循环补齐，重建时裁回 N 点。求解 Principal Component Pursuit：min ||L||_* + λ||S||_1，D=L+S，λ=1/sqrt(max(matrix.shape))。

使用增广拉格朗日的奇异值软阈值与元素软阈值更新；相对重构残差容差 1e−6，最多 500 次。输出低秩背景与稀疏分量，保存实际残差与是否达到容差。该表示针对周期结构，时序漂移会增加矩阵秩，适用性由失配结果判断。[RPCA 原论文](https://arxiv.org/abs/0912.3599)。

## 连续评分与阈值

每个方法保存原始有符号 A，不先按检测阈值清零。对每条序列计算：

- b = median(A)。
- s_A = 1.4826 × median(|A−b|)。
- s_X = 1.4826 × median(|diff(X)−median(diff(X))|) / sqrt(2)。
- s = max(s_A, s_X, 数值精度下限)，z=(A−b)/s。

单向规则 z>c；双向规则 |z|>c。主倍数 c=3，另外固定报告 c=2、4，所有倍数均展示。s_X 提供输入噪声尺度下限，避免稀疏分量的 MAD 接近零时阈值退化。该规则依赖异常相对稀疏、正常背景变化较缓的条件，是可复现的稳健启发式，**不保证指定误报概率**。K、正则参数、分数收缩与背景拟合误差仍可能影响阈值表现。

AUROC/AP 使用阈值前分数；真实及正向仿真以单向结果作为原任务比较，负向/双向场景同时列单向规则和双向规则。采用 |z| 是需要实证判断的决策扩展，不能预先声称负向检测已经有效。原 A>0 规则也按同一批输出计算，供 R1.3 对照。

异常序列的 F1=0 保留。无正标签序列的 Recall/AP 无定义，AUROC 要求两类标签；这些位置留空，无异常序列单独评价 FPR。真实未标注点按参考标签视为负类，其误报率含标注局限。

## C：初值与报告边界

使用 `nominal_s0` 和 `asymmetric_s0`。默认结果从 B 复用，随机种子 101–105 各产生一次扰动：每个起点独立均匀移动 ±0.1(N/K)，每个时长和幅值独立乘以 [0.9,1.1] 内的系数；A 初始参数仍为 0。

全部运行使用相同目标、参数和迭代次数。报告 5 个随机结果的均值、样本标准差、范围；默认值单列，保存所有初末参数和目标曲线。P/A 与真值的误差、不同初值之间的分量差异及 F1 均分别报告。这里评估有限扰动范围和固定预算下的敏感性；有限重复不能证明全局可辨识性或初始化无关。

## 统计、停止与成本

- 每个场景报告独立种子下的逐信号数据；不将不同场景当作同一条件的独立重复。
- 配对比较计算同一输入的 QPAD−基线指标差。仿真按种子重采样；真实先在录音内平均差值，再按录音重采样，录音等权。2000 次 bootstrap、固定种子 8301，报告 95% 百分位区间。5 个种子的区间精度有限。
- 配对比较列出匹配样本数和缺失数；与总体逐片段宏平均使用不同权重时在表中注明。
- QPAD 固定预算完成、QPGP 优化器停止、RPCA 残差容差分别记录。数值失败和文件缺失保留，不能视为正常完成或有效零分。
- 拟合计时包含模型初始化、周期估计和优化，CUDA 前后同步；排除文件 I/O、评价与统计。记录 CPU/GPU、软件版本与线程数。这是该运行环境下的成本，不是不同硬件的公平性能基准。
